# Import Cost Analysis

## Inflation & Import Cost Volatility

**Inflation & Import Cost Volatility:**  
Price per MT and Year-over-Year (YoY) inflation diverge significantly, showing high volatility for premium imports (Fruits) versus stability for others.  
Fruits are the primary driver of cost volatility, showing the highest prices and frequent inflation spikes, while Grains, though cheap overall, exhibit notable inflation spikes in specific years (e.g., 201).
